# Pullr

Paste any video link (YouTube, Instagram, Facebook, X, TikTok, Reddit, Vimeo and 1000+ sites) and keep the video.

Three sections: **Saved links** (every quality with its size), **Downloading** (live progress, cancel/retry), **Downloaded** (open, share, delete).

Fast parallel downloads, auto-resume, notification paste panel, share-sheet quick save. Powered by yt-dlp, which updates itself.

Build: push to `main`; GitHub Actions publishes `Pullr.apk` as a release.
